Creating a GUI Bank Balance Application

Create a simple Graphical User Interface (GUI) Bank Balance application.
	The application must obtain the BankAccount balance from a user, and then
		display that balance within a JPanel when the user selects a button.
	The program should allow for the user to deposit and withdraw funds from
		their account using a simple interface.
	The remaining balance in the account should be displayed before exiting the program.
	Ensure that your application includes the following components:
		JPanel
		JButton
		ActionListener

Students must use appropriate version control for all programmatic assignments created.
	GIT repositories should be established, and screen captures of repositories should
	be submitted with each assignment.
 
What to submit?
Your source code in text version (not screenshot).
Your entire IDE screenshot displaying source code and output.
Include additional output screenshots displaying different test cases.
Screenshot of your version control or GIT repository link 
Attach all these components into a single Microsoft Word document or submit a zip
	file containing all of these components.


Program functionality:
	Get starting balance from user
	Select option or Withdrawal or Deposit
		Display history of changes?
	Input amount to add or remove from account
	Update and display current account information/balance
	Exit button to end account changes
